software that i find useful

VSCodium (free, open source) Almost all of the code for this website is done in here. It is a fork of Visual Studio Code, so if you already use that there's not much of a difference besides the Microsoft stuff.
Adobe Animate ($23/mo, proprietary) This is what I use to make GIFs and animations, namely the homepage GIF where my persona is sitting at a director's chair. It's a very old version from back when it was called Macromedia Flash (and it came on a disc!), but they don't sell it anymore, let alone allow you to buy it outright.
MS Paint (free, proprietary) For a lot of the doodles on this site! Used very interchangeably with JS Paint, which is free and open source. (You already have this on your computer if it's running Windows.)
